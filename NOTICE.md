# Attribution and scope

The components were extracted and generalized from a project-local React UI implementation. The particle geometry is implemented with Canvas 2D and the streaming cursor with CSS; no third-party exported component code, shader, image, font or paid asset is included.

The original visual references were the **band**, **ping** and **ribbon** thinking-orb effects in the [MetalForge editor](https://metalforge.xyz/editor#effect=thinking-orbs&style=band). This is an independent implementation, not an official MetalForge package or a promise of pixel-identical reproduction. Those names describe the selected visual variants here.
